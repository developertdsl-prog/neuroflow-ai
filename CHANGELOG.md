# Changelog - NeuroFlow-AI

All notable changes to this project are documented chronologically in accordance with [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-06-26
### Added
- Enterprise-grade Multi-Agent DAG workflow orchestrator with cycle detection and parallel branch resolution.
- High-performance Vector Semantic Episodic Memory engine utilizing Cosine Similarity indexing.
- Comprehensive Real-Time Safety Guardrail Engine with PII redaction and prompt-injection shielding.
- Multi-Model Unified Gateway supporting OpenAI, Anthropic, Gemini, and Local LLM topologies.
- Full React 18 Agent Ops Console with real-time visual DAG execution telemetry and token cost auditing.

## [0.8.0] - 2026-05-18
### Added
- Sandboxed tool invocation system with timeout isolation and strict input JSON-schema validation.
- Agent Task Audit Trace system for compliance and immutable execution tracking.

## [0.5.0] - 2026-03-24
### Added
- Dynamic Prompt Template Synthesizer with variable injection and few-shot calibration.
- Vector memory pruning mechanisms with sliding window relevance decay.

## [0.2.0] - 2026-02-16
### Added
- Topological sort engine based on Kahn's Algorithm for resilient asynchronous task dependency chains.
- Rate limiting middleware with token bucket quota allocation.

## [0.1.0] - 2026-01-12
### Initial
- Core project scaffolding, MongoDB schemas, Docker configuration, and initial architectural RFC.
